# Long Way to Go

The archive of *Long Way to Go*, a comic strip by Andy Hartmann: the 1998 daily strips (January–April) and a week from January 2002. Published with GitHub Pages by the workflow in `.github/workflows/static.yml`.

## Editing the site

Every HTML page is generated by `tools/build.py`, so change the script (or `assets/site.css`) rather than the pages, then rebuild and commit the output:

```sh
pip install pillow
python tools/build.py
```

To add strips, put the week's images in a folder, add the week to `WEEKS` in `tools/build.py` and rebuild. Every link is relative, so the site works on GitHub Pages and when opened from disk.
